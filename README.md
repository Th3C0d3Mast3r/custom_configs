# custom_configs
Migrating between devices, VBoxes and systems is lowkey tough and uncool- the hassle to download the things back again, setting it up, and all the stuff that makes the system feel **HOME** takes hell lot of time, and this is something I feel should not be the case. Migrating between devices should be a simple thing, and thus, came this repo.

I am making this repo with two main things- while the directories store the custom_configs that I use *(now idk, if I will be keeping my custom configs there or nah- but the other half of this repo is for help you "capture" your system and stuff, and then, create custom_configs for you)*. 

Thus, I will mention below, how u can capture your own "custom_config" of system - although I feel, this is something that will be highly constrained to the Linux World *(for Windows, well, I will have to see `choco` and `winget` stuff for proper pacakage management and stuff- so yes, les see, how this cross-OS integration goes!)*
