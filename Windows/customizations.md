# CUSTOMIZATIONS and UTILITIES 
The following are the tools that I use for the windows customization and stuff-

- **WINDHAWK**: Using the Dock feature and Genie-like minimize.
- **RAINMETER**: This is for the Stats and stuff on the Windows Home Page.
- **SMART WIDGETS**: From the STORE itself, use for widnows widgets and stuff.
- **FLOW LAUNCHER**: This is for quick launching and stuff for searching and stuff for windows.
- **GLAZE WM**: Windows Tiling manager.
- **SPICETIFY**: For spotify customization and stuff that makes the overall looks better.
